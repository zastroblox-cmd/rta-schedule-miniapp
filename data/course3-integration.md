# Подключение адаптера 3-го курса к Mini App

Адаптер совместим с браузером и Node.js. Этот документ не подключает 3-й курс к интерфейсу автоматически: данные пока остаются отдельным черновиком.

## 1. Подключить скрипт в index.html

Перед основным скриптом приложения добавить:

```html
<script src="./data/course3-adapter.js"></script>
```

## 2. Загрузить JSON один раз

В существующую инициализацию приложения добавить асинхронную загрузку:

```js
async function loadCourse3Schedule() {
  const response = await fetch("./data/course3-review-draft.json", { cache: "no-store" });
  if (!response.ok) {
    throw new Error("Не удалось загрузить расписание 3-го курса");
  }
  const data = await response.json();
  window.Course3Schedule.setDraft(data);
}
```

Вызывать `await loadCourse3Schedule()` до первого отображения расписания выбранной группы 3-го курса. Ошибку загрузки нужно обрабатывать так, чтобы расписание других курсов продолжало работать.

## 3. Получить занятия для выбранной группы и даты

```js
const lessons = window.Course3Schedule.getLessonsForDate(
  "Ю603/О-2403",
  "2026-10-22"
);
```

Адаптер сам применяет чётность недель А/Б, разовые даты, исключённые даты, сроки действия и общие события. ISO-строка даты поддерживается без сдвига из-за часового пояса.

## Важные условия

- Не менять существующую логику и визуальный стиль 2-го курса.
- Сначала добавить группы 3-го курса в выбор групп и направлять их расписание через адаптер; остальные группы должны продолжить использовать текущую логику.
- Не преобразовывать отсутствующую аудиторию в выдуманный номер: в данных уже используется пометка «Уточняется накануне».
- Перед публикацией сверить предупреждения из `course3-integration-audit.md`, особенно нестабильные имена и пятничные записи Ю604.
- Тесты Node.js проверяют и обычный режим, и загрузку адаптера в браузероподобном окружении.
